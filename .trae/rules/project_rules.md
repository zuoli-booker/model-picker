# Trae 项目规则（指针文件）

> 本文件唯一作用：把 Trae 引导到项目的真正协作入口。不要在这里重复维护规则，唯一真相源是 AGENTS.md。

1. **必读**：打开项目后，先读仓库根目录的 `AGENTS.md`（协作模式、硬约束、协作规则、Git 规范全在里面），再读 `STATUS.md`（当前进度、参与者登记、任务看板）。
2. **开工四步、收工更新 STATUS.md、提交格式 `[智能体名] 做了什么`** 等一切规范以 `AGENTS.md` 为准。
3. 本项目是多智能体协作项目，STATUS.md 工作日志里有其他智能体（WorkBuddy 等）的工作记录，动手前先看，不要凭猜测推翻已有约定。
