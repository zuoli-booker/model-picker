## 1. 目标人群：「轻开发者」

| 维度 | 描述 |
|---|---|
| 身份 | 普通上班族（运营/设计/产品/行政/市场等非技术岗） |
| AI 经验 | 用过 WorkBuddy、Trae、豆包、Kimi 等应用级工具，不是纯小白 |
| 核心痛点 | ①订阅套餐贵/额度不够；②应用能力边界卡住自己的想法，想按自己的需求调 API |
| 能力边界 | 代码不强，但爱学习、能照教程复制粘贴、能操作终端 |
| 心理诉求 | 省钱 + 掌控感 + "我也能折腾 AI"的成就感 |
| 性别结构 | 估算男 60-70%（AI 工具大众用户性别均衡：豆包女 55%、DeepSeek 1:1；B站技术人群男 70-88%——本人群在中间偏后段） |

**定位原则**：
- **人群做定位，场景做选题库**（不锁死细分场景；每篇内容从具体场景切入，用人群共性痛点串联）
- 服务"想用"的人，不是"想学"的人——三分钟上手、直接给配置、复制粘贴就能用

## 2. 平台组合

| 平台 | 角色 | 核心依据 |
|---|---|---|
| **小红书** | **主阵地**：获客 + 搜索长尾 | 25-40 学习型上班族浓度最高；日均搜索 8 亿次吃"XX模型怎么用/多少钱"长尾；男性用户约 1.1 亿且平台正转型"AI 时代 App Store"（16 万开发者 +220%）；**左力的本行方法论零学习成本** |
| **B站** | **并行试水**：深度信任 + 男性触达 | 科技用户 2 亿、男 70%、AI 兴趣人群 8000 万、AI 内容播放年增 80%；打法=图文转录屏视频（不出镜），每 2-3 周一条 |
| **微信群/知识星球** | **私域**：聚人 + 留存 + 转化 | 该人群"抄作业"刚需极强；微信群起步（免费），50 人后评估知识星球 |
| GitHub / V2EX / 掘金 | 工具冷启动 | 策略生成器开源发布时各发一帖，不做人群运营 |
| 微信公众号 | 沉淀存档 | 深度横评/月报长文，不做主战场 |
| 抖音/快手、知乎 | **不做**/低优先 | 人群错配 / 社区氛围变迁 |

**性别互补逻辑**：小红书（女 72%）+ B站（男 70%）两条腿组合后的人群结构，比任何单一平台都更接近轻开发者的真实分布。合理预期：小红书男性粉丝占 25-35%，不追求站内 1:1。

## 4. 内容风格铁律

1. **零代码默认值**：所有教程假设读者不会写代码
2. **每篇有可带走的东西**：配置块/提示词/清单
3. **成本透明**：每个方案标价
4. **语感性别通吃**：封面/标题用"3C 测评风"（终端截图 + 数据图表 + 大数字标题），不用精致生活方式风；标题句式"一年省 1420 元，账算给你看"，不用"姐妹们！这个方法太好用了吧"；人设"爱折腾工具的运营人"（职场身份天然中性）

## 5. 北极星指标

- **收藏率 > 8%**（收藏 = 想照着做的意图信号；该人群收藏远多于点赞）
- 辅助：评论区"求教程/求配置"频率、私域进群率、配置块被复制使用的反馈
- **性别验证闸门**：冷启动 8-12 篇后查小红书后台，男性粉丝 <20% = 语感跑偏需修正；≥30% = 触达正常

## 6. 冷启动节奏与止损

- 前 4 周发 8-12 篇小红书（每周 2 篇）+ 2-3 条 B站录屏
- 选题批量规划：首批 30 篇一次规划完、批量生产（复用左力 48 家医院矩阵的打法）
- 评论区 24h 内回复；每条"求教程"评论都是下篇选题
- **止损**：两轮（各 4 周）无水花 → 停内容运营，工具转纯开源维护模式

## 7. 竞争空位（为什么能立住）

- "非程序员实操 + 成本账 + 可复制配置交付"的组合无人占位
- 现有教程默认读者会 Python（CSDN/掘金语感），把大量潜在用户挡在门外——**非程序员视角是结构性空白**
- 独有弹药：48 家医院小红书矩阵的真实多模型工作流素材，别的博主编不出来
- 内容方法论与 L3 智能体部署指令同构（"复制这段话给 AI 助手替你执行"）——内容、社群、产品是一条链
